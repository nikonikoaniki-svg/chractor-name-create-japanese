# キャラ名工房（日本人編）完全版

## データ構成
- 全データ: 17,000項目
- 姓プール: 5,000項目
- 完成名: 3,000項目
  - 男性: 1400
  - 女性: 1400
  - 中性的: 200
- 創作部品・字面パターン・ルール: 9,000項目
- 字面・漢字構成パターン: 3,000項目

## 重要な仕様
- 辞書は「漢字＋タグ」のみです。
- 読み仮名・発音・音パターンは内部にも保持しません。
- 男性・女性・中性的な完成名は別プールで管理します。
- 男性名と女性名の表記重複は0件です。
- 姓と名は別々に回せます。
- 姓・名それぞれに「戻る」があります。
- 直近100候補を再抽選しないようにしています。
- 直近に使われた漢字は出現確率を下げ、同じ字面の連発を抑えます。
- お気に入りは漢字表記だけを保存します。
- ネット接続不要。index.htmlを開けば動きます。

## 読み方について
読み方はアプリ側で指定しません。利用者がキャラクターに合わせて自由に考える仕様です。
